Направление SELF-SERVICE: владелец держит клинику кнопками в админ-чате.
Инкременты 1 (каркас консоли) и 2 (врачи/услуги/расписание/выходные)
закрыты. Инкремент 3 — **презентационный**: привести админ-карточки и меню
к hero-стилю пациентского UI (P-7). Решение пользователя по глубине —
**паритет с пациентским** (не «лёгкая» и не «полная виз-система»).

Чисто визуальный инкремент: ноль изменений поведения, callback'ов, БД,
миграций. Только строки рендера в `telegram/admin_console.py`.

## Контекст

Админ-ответы уже уходят с `parse_mode=HTML` (`<b>` и эмодзи рендерятся —
подтверждено живым тыком 14.06). Пациентский стиль (`dialog/replies.py`):
emoji-якоря на полях, hero-заголовки (`✅ <b>ЗАПИСЬ ПОДТВЕРЖДЕНА</b>`),
пустые строки между блоками. Текущие админ-карточки плоские:
`✨ <b>Чистка</b>\nЦена: …\nДлительность: …\nСтатус: активна`.

## Визуальный словарь (единый для всех поверхностей)

Карточка сущности: `{emoji} <b>{Имя}</b>` → пустая строка → поля по одному
на строку с emoji-якорем → статус-бейдж.

Услуга:
```
✨ <b>Чистка</b>

💰 Цена: 350 000 сум
⏱ Длительность: 30 мин
🟢 Активна
```

Врач:
```
🧑‍⚕️ <b>Akmal aka</b>

📅 График: Пн–Сб 09:00–13:00, 14:00–18:00
⏲ Буфер: 10 мин
📆 Календарь: не привязан
🟢 Активен
```

Соглашения:
- **Статус-бейдж** — `🟢 Активна/Активен` / `⚪ Скрыта/Скрыт` (без «Статус:»,
  бейдж = отдельная строка). Услуга — женский род, врач — мужской.
- **Кнопки действий** — emoji-префикс: `💰 Изм. цену`, `⏱ Изм. длит.`,
  `⛔ Скрыть`, `✅ Показать`, `🗑 Удалить совсем`, `👤 Имя`, `⏲ Буфер`,
  `📅 Расписание`, `◀ Назад`/`◀ {Раздел}`.
- **Заголовки разделов** — `{emoji} <b>{Раздел}</b>` + строка-подсказка
  («Выберите услугу 👇»).
- **Нотисы** — первой строкой `✅ {текст}` / `⛔ {текст}` + пустая строка
  перед карточкой/списком (паттерн уже есть, причёсываются формулировки).
- **Промпты ввода** — `{emoji} <b>{Поле}</b>` + пустая строка + инструкция.
- **Empty-states** — дружелюбно: `📅 Закрытых дней нет — клиника работает
  по графику.`; `Все услуги каталога уже добавлены ✅`.
- Подстановки (имя/адрес/причина) — `_esc()` как сейчас; лейблы кнопок
  Telegram не парсит — не экранируются.

## Охват поверхностей (render-методы admin_console.py)

- Меню: `main_menu`, `_services_menu`, `_doctors_menu`, `_faq_menu`

- Карточки: `_service_card`, `_doctor_card` — hero-стиль.

- Нотисы деактивации/активации/удаления/обновления — формулировки под
  словарь (✅/⛔ + предмет).

## Реализация

Только строки рендера в `telegram/admin_console.py`. Два хелпера для
консистентности (модульный уровень):
- `_status_badge(is_active: bool, female: bool) -> str` →
  `🟢 Активна`/`🟢 Активен` / `⚪ Скрыта`/`⚪ Скрыт`.
- `_field(emoji: str, label: str, value: str) -> str` →
  `f"{emoji} {label}: {value}"` (необязательный, если упрощает; иначе
  инлайн).

Ноль изменений: поведения, callback-схемы (`adm:*`), pending-видов, БД,
миграций, `onboard.py`, репозиториев. Воркер не трогается.
